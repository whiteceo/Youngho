부록 10 · AI 제공 방식

APPENDIX 10

두 방식 모두 가능하며, 기본 방식은 파일럿 후 정한다

ⓐ AI 포함형

당사가 Amazon Bedrock(AWS의 AI 모델 이용 서비스)으로 제공. 사용량 한도 + 초과분 청구(실비 + 수수료 15~20%)

장점

도입이 간편, 서울 리전(AWS 서울 데이터센터) 안에서 처리

유의

50인 기준 월 약 14만(가벼운 사용)~65만 원(활발한 사용). 한도 설정 필수

ⓑ AI 연결형

고객이 쓰는 AI 구독(ChatGPT·Claude 기업 요금제 등)이나 API 키를 연결. 당사는 정책·권한·교육 관리

장점

정액 구독이 API 종량 과금보다 대체로 저렴. 당사 AI 원가 없음

유의

사용 내역은 해당 서비스 관리 기능이 주는 범위까지만 확인 가능. Track 2는 ⓑ만 사용

AWS는 2026-09-29부터 서울 리전에서 Claude Opus 5·Sonnet 5를 리전 내 처리로 제공. ⓐ를 택하면 “데이터가 국내 리전 밖으로 나가지 않음”을 말할 수 있다

ⓐ 사용료: Claude Sonnet 5 Bedrock 단가(입력 $2.20, 출력 $11.00 / 100만 토큰), 50인·월 20 영업일, 인당 하루 10~30회
