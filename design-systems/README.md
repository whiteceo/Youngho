# 발표 자료 디자인 시스템 (2종)

사업 기획 발표 자료를 만들 때 아래 둘 중 하나를 고릅니다. 두 폴더는 같은 구조입니다.

| 폴더 | 한 줄 | 이럴 때 |
|---|---|---|
| [report-light/](report-light/README.md) | 흰 바탕, 보라 강조색 하나, 표·숫자 중심의 보고서형 | 경영진 보고·검토 판정처럼 숫자와 근거를 차분히 읽혀야 할 때(이번 AI 업무 플랫폼 검토 덱) |
| [modern-grid/](modern-grid/README.md) | 어두운 차콜 바탕, 라임 그린 강조색 하나, 직각 카드·해치의 컨설팅형 | 투자·외부 발표처럼 인상이 강해야 하고 핵심 수치 몇 개로 끌고 갈 때 |

공통 구조
- `README.md`: 용도, 특징, 규칙
- `tokens.json`: 색·글자·간격·모서리(같은 형식: 각 항목 name·value·usage)
- `base.css`: 토큰 변수 + 공통 요소 CSS
- `samples/`: 샘플 스크린샷

공통 원칙(두 시스템 모두)
- 제목은 그 장의 결론 한 문장(액션 타이틀), 강조색은 하나
- 약어·전문 용어는 나오는 장마다 하단 각주로 풀이
- 발표용(PC 화면). 인쇄는 고려하지 않음
