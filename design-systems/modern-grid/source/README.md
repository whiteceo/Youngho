# Modern Grid

컨설팅 보고서용 다크 모드 슬라이드 시스템. 다크 차콜 바탕에 라임 그린 하나만 포인트로 쓰고, 직각 카드와 45° 해치 패턴으로 위계를 만든다. Etsy의 "Consulting Presentation Template — modern grid series"(Provokitive) 다크 모드 미리보기 이미지 10장을 한 장씩 보고 정리했다. 색은 이미지 픽셀에서 추출한 근사치, 폰트는 한글용 대체 폰트다.

## 원칙

1. **포인트 컬러는 하나.** `green-500`만 강조에 쓴다. 노랑(`yellow-500`)은 섹션 번호 점과 차트, 파랑(`blue-500`)은 차트에만.
2. **제목이 결론이다.** 모든 본문 슬라이드는 액션 타이틀(`slide-title`): 완결된 한 문장, 최대 2줄, 마침표 없음.
3. **근거 → 데이터 → 결론.** 왼쪽 인사이트 카드, 가운데 차트, 오른쪽 그린 콜아웃 패널의 3단 흐름이 기본.
4. **직각, 그림자 없음.** 모든 면은 `radius-none`. 깊이는 `bg` → `surface` → `surface-2` 명도 단계로만 표현.
5. **해치는 '특별함' 표시.** 전망치, 현재 단계, 검토 대상, 아이콘 박스 배경 — 실적·확정과 구분해야 할 때만.

## 색

| 역할 | 토큰 | 값 |
|---|---|---|
| 배경 | `bg` | #242424 |
| 카드 면 | `surface` / `surface-2` | #303030 / #3a3a3a |
| 푸터 바 | `footer` | #3b3b3b |
| 선 | `line` / `line-strong` | #4a4a4a / #5e5e5e |
| 텍스트 | `ink` / `ink-2` / `ink-3` | #ffffff / #c8c8c8 / #a3a3a3 |
| 포인트 | `green-500` | #84bd26 |
| 그린 단계 | `green-600` / `green-800` / `green-panel` | #66901e / #426012 / #3a4a1c |
| 차트 보조 | `yellow-500` / `blue-500` / `gray-500` | #f0ae24 / #1ea8d8 / #8a8a8a |

**대비 주의:** 원본은 그린 면 위에 흰 글자를 쓰지만 대비가 2.3:1이다. 24px 이상 굵은 숫자에만 흰색(`on-accent`)을 쓰고, 작은 글자는 `on-accent-ink`(#1c1c1c)로 쓴다.

## 타이포그래피

원본은 네오 그로테스크 산세리프 한 패밀리. 한글 환경에서는 두 역할로 나눈다.

- `sans` — **Pretendard**(권장, 무료). 없으면 Noto Sans KR. 제목, 본문, 라벨.
- `num` — **Inter Tight**. 큰 숫자, 섹션 번호, 로고. 한글 문장 안의 숫자도 이 폰트로 바꾸면 원본 느낌이 산다.

위계는 크기보다 **굵기 대비**로 만든다: 디바이더 제목 700 / 부제 300을 같은 36px로. 1280×720 기준 스케일 — 섹션 번호 300 · KPI 120 · 수치 44 · 디바이더 36 · 제목 30 · 카드 제목 16 · 본문 13 · 라벨 12 · 아이브로 11 · 캡션 10.

## 레이아웃 (1280×720, 16:9)

- 여백: 좌우 `slide-margin` 60px, 상단 48px, 하단 푸터 바 `footer-h` 44px("03 | 발표 주제 – 2026").
- 그리드: 2열(1:1, 1:2) 또는 3열, 거터 `space-6` 24px.
- 원본에서 확인한 슬라이드 유형:
  - **표지**: 왼쪽 텍스트(로고, 질문형 제목 굵게 + 부제 가늘게, 작은 그린 버튼, URL) / 오른쪽 40% 풀블리드 사진.
  - **섹션 디바이더**: 거대한 숫자 + 노란 사각 점 + 제목/부제 (`SectionDivider`).
  - **KPI 한눈에 보기**: "FY**2026** at a Glance" + 초대형 수치 + 3열 지표 (`KpiHero`), 또는 왼쪽 지표 리스트 + 오른쪽 세로 사진.
  - **인사이트 + 스탯**: 왼쪽 아이브로·제목, 오른쪽 `StatList`.
  - **근거 + 차트 + 결론**: `InsightCard` + 차트(`BarChart`, 원 다이어그램, 파이) + `Callout`.
  - **3열 컴포넌트**: 아이콘·제목·설명 3개 위에, 아래로 사진 / 그린 지표 타일 / 사진.
  - **매트릭스**: `Matrix`, 포지셔닝 버블 차트(사분면 + 원), 가격 비교 `DataTable`.
  - **프로세스**: `ProcessSteps`, 원형 화살표 사이클, 퍼즐 도넛.
  - **팀 소개**: 왼쪽 소개+이름/직함 표, 오른쪽 3×2 인물 사진 그리드.

## 차트

색 순서 `green-500` → `gray-500` → `yellow-500` → `blue-500` → `green-800`. 강조할 하나만 그린, 비교군은 회색. 전망·추정은 그린 해치. 차트 제목은 `surface-2` 탭 라벨. 원(버블, TAM/SAM/SOM, 단계 원)만 `radius-full`.

## 아이콘과 이미지

- 아이콘: 단색 흰색 라인/솔리드 아이콘. 52px 회색 해치 박스 + 그린 밑줄(`StatList`) 또는 단독.
- 사진: 차분한 톤의 도시·건축·오피스·기술 사진. 모서리 직각, 슬라이드 가장자리까지 풀블리드하거나 카드 칸에 꽉 채운다.
- 로고: 원본의 "BCK Consulting."은 샘플이라 포함하지 않았다. 텍스트 로고는 `num` 700, 일부 글자만 green-500, 끝에 마침표.

## 문체

- 제목: "~하고 있다", "~해야 한다"처럼 결론을 말하는 평서문.
- 숫자는 단위와 기준 시점을 함께("24.5% · 2026 기준").
- 불릿은 3개, 한 줄 이내. 느낌표·이모지 없음.
