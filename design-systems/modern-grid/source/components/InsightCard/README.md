# InsightCard

인사이트 카드 — surface 면에 좌측 상단 그린 바, 제목·본문·강조 수치.

`surface` 배경, 좌측 상단에 `accent-bar` 두께 × 44px 그린 바. 제목 `card-title`, 본문 `body`(ink-2), 강조 수치 34px green-500, 그 아래 green-500 주석.

- 변형: **지표 타일** — 3열 카드(아이콘+제목 / 이미지 / 지표) 중 가운데를 `green-500` 면으로 채운다. 큰 숫자는 흰색(원본) 가능, 작은 글자는 `on-accent-ink`.
- 모서리는 항상 `radius-none`.
