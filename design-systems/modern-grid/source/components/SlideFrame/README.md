# SlideFrame

슬라이드 기본 틀 — 액션 타이틀, 본문 그리드, 하단 푸터 바.

1280×720 기준. 좌우 여백 `slide-margin`(60px), 상단 48px, 하단에 `footer` 색 푸터 바(`footer-h` 44px)에 "페이지 번호 | 발표 주제 – 연도".

- 제목은 `slide-title` 스타일의 **액션 타이틀**: 결론을 완결된 한 문장으로, 최대 2줄. 핵심 단어 하나만 `green-500`.
- 본문은 2·3열 그리드, 거터 `space-6`(24px). 왼쪽 근거 → 가운데 데이터 → 오른쪽 결론 순서.
- 사용처가 채워야 할 것: 제목 문장, 본문 블록, 푸터의 주제 텍스트.
