# Report Light (디자인 시스템 v2)

**한 줄:** 흰 바탕에 보라(#6500C3) 강조색 하나, 표·숫자·각주 위계가 분명한 경영 보고서형 슬라이드 시스템(1920×1080). 「AI 업무 플랫폼 사업 타당성 검토」 발표 자료 44장에 쓴 시스템입니다(white 컨펌 2026-10-25, round 10~14 반영).

**이럴 때:** 경영진 보고, 사업성 검토·판정처럼 숫자와 근거를 차분히 읽혀야 하는 덱. 표와 차트가 많은 장.

## 파일
- `tokens.json`: 색·글자·간격·모서리
- `base.css`: 토큰 변수 + 공통 요소(제목, 장 이름, 진행 표시, 표, 콜아웃, 패널, 상태 칩, 하단 두 층)
- `design-system.html`: 규칙 시트 원본(브라우저로 열기), `samples/00-design-system-sheet.png`가 그 화면
- `samples/01-summary.png`(요약 장), `02-pnl-chart-table.png`(차트 옆 표)
- `fonts/`: Spoqa Han Sans Neo 3종, Noto Serif KR(起承轉結 4글자 부분 집합), OFL 라이선스
- 생성기·검사 스크립트 원본: `/mnt/project-files/deck/v2-src/` (gen2/lib.py가 이 규칙의 실제 구현)

## 위계
- 제목 52 Bold = 그 장의 결론(액션 타이틀, 명사형 종결). 아래 28 회색 한 줄에 조건·범위
- 강조는 한 장에 1~2곳: 핵심 숫자와 판정어를 보라 글자로. 형광펜(글자 배경)은 artifact 엔진이 그리지 못해 쓰지 않음
- 글자 크기 52 / 28 / 26 / 24 / 22 / 20 / 18, 굵기 Regular·Medium·Bold 셋(글꼴 이름으로 바꿈)
- 장 이름(20 Bold 보라)과 오른쪽 위 진행 표시 起承轉結(현재 단계만 보라 칩)

## 요소 규칙
- 표: 바깥 상자·세로선 없이 위 2px 잉크 선 + 행 1px 선. 머리 20 Medium 연회색. 첫 열은 정렬선(왼쪽 120px)에 맞춤. 강조 행은 바탕 없이 첫 칸만 보라 굵게. 행 여백 10(행이 적으면 최대 24). 차트 옆 표는 차트 높이에 맞춤
- 콜아웃: 연보라 바탕 + 왼쪽 라벨 열(칩 없음), 안쪽 16·24, 한 장에 하나
- 패널: 상자 대신 위 2px 선. 패널 머리는 칩이 아니라 20 굵은 분류 라벨. 패널 안 하위 블록은 1px 선만
- 상태 칩(미충족·높음·조건부·미정 등): 테두리형(1.5px #B0B8C1, 회색 글자), 강한 것은 2px 회색 테두리 + 잉크 굵게. 빨간 칩 없음. 칩은 표 안 상태값에만
- 차트: 가로 격자선만, 의미 있는 점에 라벨, 제목과 같은 시간 기준 하나
- 간지: 3D 일러스트 없이 큰 번호(01~04, A) 타이포
- 이미지 장식 없음(보고서에 팬시한 일러스트 쓰지 않음)

## 하단 두 층(모든 장 같은 위치: 바닥에서 52px)
- 1층 설명 22 회색: 항상 "기본 조건:" 같은 굵은 라벨로 시작, 문장 사이 공백 한 칸
- 2층 각주 18 연회색: 용어 풀이·출처, 용어는 굵게. 1층이 없는 장은 2층만 같은 위치·형식
- **약어·전문 용어는 처음 나온 장만이 아니라 나오는 장마다 2층에 풀이**(발표는 장을 건너뛰어 보는 경우가 많음). 생성기가 용어 사전(GLOSS)으로 자동 점검·추가
- 본문 아래 끝은 하단 위쪽보다 24px 이상 위

## 간격·정렬
- 8의 배수: 16(칸 안쪽) · 24 · 32(덩어리 사이) · 48. 제목과 부제 사이만 12
- 화면 여백 좌우 120, 위 88. 장 이름·제목·표 첫 열·각주의 왼쪽 끝을 120px 선 하나에 맞춤

## 문체
- 객관적 컨설턴트 톤, 제목·불릿은 명사형 종결, 발표 메모는 문장
- 12개월 이상 기간은 "년+개월", 원문자 번호 쓰지 않음, 영어 용어는 처음에 풀이(그리고 위 각주 규칙)

## 애니메이션(발표용 웹 번들)
- 내용 확정 뒤 마지막에. 장 전환 0.25초 페이드
- 장이 열리면 자동으로 차례 등장(발표자가 단계마다 누르지 않음): 제목(결론) → 본문 덩어리 차례(최대 5) → 하단 → 제목 강조색. 단계 간격 0.5초 이하, 장 전체 2.2초 이내. 선 그래프는 왼쪽→오른쪽 0.8초 그리기. 이동 효과 없음
- → 한 번이면 등장 중이어도 바로 다음 장, ←는 이전 장 완성 상태. 표지·간지·종합 판정 장은 페이드만. 주소에 `?all`이면 단계 없이 모두 표시
