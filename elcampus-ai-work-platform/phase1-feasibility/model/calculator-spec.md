# 손익 계산기 명세 (발표 자료용)

이 명세는 「AI 업무 플랫폼 사업 타당성 검토」 5장 손익 모델(model_v6.py)을 발표 자료의 계산기로 옮기기 위한 입력값, 계산식, 출력값을 정리한 것이다. 단위는 모두 만 원, 기간 단위는 월이다.

## 1. 입력값

| 입력 | 기본값 | 조정 범위(권장) | 근거 |
|---|---|---|---|

| 매달 신규 고객 수 N | 3 | 1~6 | 5.2 (보수적 기준 3곳) |

## 2. 계산식

사내 인력 월 비용 I = 개발자 투입 × 개발자 월 인건비 + UIX 투입 × UIX 월 인건비 (직접 입력값이 있으면 그 값). 기본값 2.0 × 775 + 1.0 × 516 = 2,066.

출시 전 투자 CAPEX = 일회성 현금 + PM × 개발 기간 + (사내 인력 포함이면) I × 개발 기간. 기본값 사내 인력 포함 25,715, 현금 기준 7,121.

월 고정비 F(m) = 월 고정 현금 + PM + (사내 인력 포함이면) I. 축소 민감도를 켜면 지정 개월 이후 I 대신 축소 금액을 쓴다. 기본값 3,223.5 / 1,157.5.

출시 후 m개월째(m = 1, 2, …, 120):

- 고객 수 n(m) = n(m−1) × (1 − 이탈률) + N, n(0) = 0
- 매출 = n × ARPU
- 영업손익 = n × (ARPU − 변동비) − F(m) − N × 온보딩 비용
- 누적 손익 = −CAPEX + 영업손익의 누적 합

## 3. 출력값

| 출력 | 정의 |
|---|---|
| 월 흑자 전환 | 영업손익이 처음 0 이상이 되는 출시 후 개월과 그때 고객 수 |
| 투자 회수(착수 후) | 누적 손익이 처음 0 이상이 되는 출시 후 개월 + 개발 기간. 10년 안에 없으면 "못 함" |
| 최대 누적 적자 | 누적 손익의 최솟값 |
| 연도별 손익 | 12개월마다 고객 수, 매출, 변동비, 고정비, 온보딩, 영업손익, 누적 손익 |
| 필요 ARPU(목표 이익률) | 출시 후 3년차 영업이익 ≥ 목표 이익률 × 3년차 매출이 되는 최소 ARPU(이분 탐색, 20~600) |
| 필요 ARPU(목표 회수 기간) | 착수 후 회수 기간 ≤ 목표 연수가 되는 최소 ARPU |
| 정상 상태 참고식 | 고객 수 K = N ÷ 이탈률일 때 ARPU = 변동비 + (F + N × 온보딩) ÷ K, 이익률 m이면 ÷ (1 − m) |
